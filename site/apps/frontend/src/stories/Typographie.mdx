# Typographie

Lue dans `src/design/tokens.css` à chaque build.

## Les familles

{fonts.map((font) => (

  <div key={font.name}>
    <h3>

## Les tailles

Chaque classe `text-…` du thème, avec la hauteur de ligne, la graisse et l'approche que Tailwind pose avec elle. Les tailles en `clamp()` suivent la largeur de la fenêtre.

<table>
  <thead>
    <tr>
      <th>Classe</th>
      <th>Taille</th>
      <th>Ligne</th>
      <th>Graisse</th>
      <th>Approche</th>
    </tr>
  </thead>
  <tbody>
    {sizes.map((row) => (
      <tr key={row.name}>
        <td>
          <code>text-{row.name}</code>
        </td>
        <td>
          <code>{row.size}</code>
        </td>
        <td>{row.lineHeight ?? '—'}</td>
        <td>{row.weight ?? '—'}</td>
        <td>{row.tracking ?? '—'}</td>
      </tr>
    ))}
  </tbody>
</table>

{sizes.map((row) => (

  <p
    key={row.name}
    style={{
      fontSize: row.size,
      lineHeight: row.lineHeight ?? undefined,
      fontWeight: row.weight ?? undefined,
      letterSpacing: row.tracking ?? undefined,
      margin: '0 0 0.5em',
    }}
  >
    <code style={{ fontSize: '0.75rem', marginRight: '1rem' }}>text-{row.name}</code>
    {m.hero_title()}
  </p>
))}
